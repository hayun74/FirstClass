# Design System — 샘표 웹사이트 리뉴얼

> 이 문서는 `sempio/index.html`, `sempio/css/main.css`, 그리고 공통 초기화 파일 `../css/default.css`를 기준으로 작성한 서브페이지 제작용 디자인 가이드입니다. 기록된 값은 현재 코드에서 확인한 값이며, 별도 표기가 없는 수치나 색상은 임의로 추가하지 않았습니다.
>
> **적용 범위:** 메인 페이지에서 확인되는 시각 규칙을 서브페이지에도 이어가기 위한 기준입니다. 기존 메인 페이지의 디자인이나 코드를 변경하는 문서가 아닙니다.

## 1. Project Overview — 사이트 목적 및 디자인 방향

### 프로젝트 개요
- 브랜드: 샘표
- 프로젝트: 샘표 웹사이트 메인 페이지 리뉴얼
- 구현 방식: HTML, CSS, JavaScript
- 기준 페이지: `sempio/index.html`
- 스타일 파일: `sempio/css/main.css`
- 기본 초기화: `../css/default.css`
- 기본 서체 파일: `../font/css/pretendardvariable.css`

### 웹사이트의 목적
메인 페이지는 샘표의 기업 정체성과 제품, 우리맛 연구·체험 콘텐츠, 공지·뉴스·SNS 소식을 한 페이지에서 소개합니다. 방문자가 먼저 브랜드의 비전과 가치를 이해하고, 대표 제품과 관련 콘텐츠를 탐색한 다음 소식과 SNS로 관심을 확장하도록 콘텐츠가 구성되어 있습니다.

### 디자인 방향
- **브랜드 중심:** 샘표 레드 계열을 주요 제목과 강조 요소에 사용합니다.
- **콘텐츠 중심:** 이미지와 짧은 설명을 함께 배치해 기업 가치, 제품, 연구 활동을 직관적으로 전달합니다.
- **명확한 정보 위계:** 섹션 제목, 카드 제목, 설명, 날짜 순으로 정보의 중요도를 구분합니다.
- **여백과 정돈:** 넓은 섹션 여백과 최대 너비 컨테이너를 활용해 콘텐츠를 정돈합니다.
- **부드러운 인터랙션:** 메뉴, 카드 이미지, 버튼, 스크롤 진입 요소에 짧은 전환 효과를 적용합니다.

이는 현재 메인 페이지에서 관찰되는 구성에 대한 분석이며, 브랜드의 공식 디자인 원칙을 별도로 인용한 것은 아닙니다.

## 2. Brand Identity — 브랜드 특성과 시각적 정체성

### 시각적 특징
- **핵심 색상:** 브랜드 레드 `#ED1C24`와 딥 레드 `#B61C21`를 강조 색으로 사용합니다.
- **기본 색상:** 거의 검정에 가까운 텍스트 `#171717`, 회색 텍스트 `#666666`, 흰색 배경을 중심으로 구성합니다.
- **이미지 활용:** 기업 가치와 우리맛 콘텐츠는 사진을 크게 보여주고, 카드 이미지에는 둥근 모서리를 적용합니다.
- **타이포그래피:** Pretendard Variable을 사용하며 굵기와 크기 차이로 제목과 설명을 구분합니다.
- **브랜드 표현:** 발효·장·한식·우리맛이라는 콘텐츠를 사진과 문구로 전달하고, 레드 컬러로 브랜드 인상을 반복합니다.

### 서브페이지 적용
서브페이지에서도 레드를 모든 영역에 넓게 사용하기보다 페이지 제목, 주요 강조 문구, 핵심 CTA, 선택 상태 등 시선이 필요한 곳에 사용합니다. 본문과 일반 배경은 기존 중립 색상 체계를 우선합니다.

## 3. Design Principles — 디자인 설계 의도 및 핵심 원칙

1. **일관된 브랜드 색상:** 동일한 역할에는 동일한 컬러 토큰을 사용합니다. 같은 목적의 버튼이나 제목이 페이지마다 다른 빨간색을 사용하지 않도록 합니다.
2. **정보 위계 유지:** 페이지 제목 → 섹션 제목 → 카드 제목 → 본문·보조 정보 순서가 명확해야 합니다.
3. **콘텐츠 우선:** 이미지와 텍스트는 장식보다 정보를 전달하는 역할을 우선합니다. 이미지에는 내용을 설명하는 대체 텍스트를 작성합니다.
4. **정렬 기준 통일:** 주요 본문은 공통 컨테이너 안에 배치하고, 섹션 제목과 콘텐츠의 좌우 기준선을 맞춥니다.
5. **반복 컴포넌트 재사용:** 같은 역할의 버튼, 카드, 링크, 날짜 표시에는 기존 패턴을 재사용합니다.
6. **상태를 색상과 움직임으로 표현:** Hover, Focus, Active 상태를 구분하되 기본 상태의 가독성을 해치지 않습니다.
7. **반응형 우선:** 고정 너비를 무조건 유지하지 않고 화면이 좁아지면 그리드 열 수와 여백을 줄입니다.

## 4. Color System — 컬러 시스템

현재 `:root`에 정의된 Primitive 및 Semantic CSS 변수입니다. 새 페이지에서는 HEX를 반복 입력하기보다 아래 변수를 우선 사용합니다.

### 4-1. Primitive tokens

| 변수명 | 값 | 기본 용도 |
|---|---|---|
| `--red-brand` | `#ED1C24` | 브랜드 레드, 강조 및 Hover |
| `--red-deep` | `#B61C21` | 딥 레드, 주요 제목·강조 |
| `--red-50` | `#FFF0F0` | 연한 레드 배경 |
| `--gray-50` | `#F7F7F7` | 밝은 섹션·카드 배경 |
| `--gray-100` | `#F1F1F1` | Hover 배경 |
| `--gray-200` | `#E5E5E5` | 기본 경계선 |
| `--gray-300` | `#CFCFCF` | 강조 경계선 |
| `--gray-400` | `#A9A9A9` | 비활성·보조 UI |
| `--gray-600` | `#666666` | 보조 텍스트 |
| `--gray-900` | `#171717` | 기본 텍스트 |
| `--white-100` | `#FFFFFF` | 흰색 배경·역상 텍스트 |

### 4-2. Semantic tokens

| 역할 | 변수명 | 연결 값 | 적용 상황 |
|---|---|---|---|
| Accent | `--accent-brand` | `--red-brand` | 브랜드 강조 |
| Accent | `--accent-soft` | `--red-50` | 연한 강조 배경 |
| Action | `--action-primary` | `--red-deep` | 주요 액션·푸터 배경 |
| Action | `--action-primary-hover` | `--red-brand` | 주요 액션 Hover |
| Action | `--action-secondary` | `--white-100` | 보조 액션 배경 |
| Action | `--action-secondary-border` | `--red-deep` | 보조 액션 테두리 |
| Action | `--action-secondary-text` | `--red-deep` | 보조 액션 텍스트 |
| Action | `--action-neutral` | `--gray-400` | 중립 UI |
| Action | `--action-neutral-hover` | `--gray-600` | 중립 UI Hover |
| Border | `--border-default` | `--gray-200` | 일반 구분선 |
| Border | `--border-strong` | `--gray-300` | 강조 테두리 |
| Border | `--border-brand` | `--red-deep` | 브랜드 강조 테두리 |
| Text | `--text-primary` | `--gray-900` | 기본 본문·제목 |
| Text | `--text-secondary` | `--gray-600` | 보조 설명 |
| Text | `--text-tertiary` | `--gray-400` | 보조 정보 |
| Text | `--text-inverse` | `--white-100` | 어두운 배경 위 텍스트 |
| Surface | `--surface-default` | `--white-100` | 기본 표면·카드 |
| Surface | `--surface-brand` | `--red-brand` | 브랜드 표면 |
| Background | `--background-default` | `--gray-50` | 기본 옅은 배경 |
| Background | `--background-hover` | `--gray-100` | Hover 배경 |
| Background | `--background-accent` | `--red-50` | 연한 브랜드 배경 |

### 컬러 사용 규칙
- 기본 본문은 `var(--text-primary)`, 보조 설명은 `var(--text-secondary)`를 사용합니다.
- 흰색 바탕의 기본 카드·섹션은 `var(--surface-default)`, 옅은 구분 영역은 `var(--background-default)`를 사용합니다.
- 주요 강조 제목에는 메인 페이지에서 반복되는 `var(--red-deep)`를 우선 사용합니다.
- 주요 버튼의 기본/호버 상태는 `--action-primary` / `--action-primary-hover`를 사용합니다.
- 투명 오버레이와 그림자에는 현재 CSS에 작성된 rgba 값이 있으나, 별도 색상 토큰으로 정의되어 있지는 않습니다. 새 페이지에서 임의로 새로운 토큰인 것처럼 취급하지 않습니다.

## 5. Typography — 타이포그래피

### 글꼴
- 기본 글꼴: `"Pretendard Variable", sans-serif`
- HTML에서 `../font/css/pretendardvariable.css`를 불러옵니다.
- 별도의 서체가 필요한 근거는 현재 코드에서 확인되지 않으므로 서브페이지도 동일한 기본 글꼴을 사용합니다.

### 메인 페이지에서 확인되는 글자 스타일

| 요소 / 사용 상황 | 크기 | 굵기 | 행간 |
|---|---:|---:|---:|
| Vision Eyebrow | 27px | 500 | 1.5 |
| Vision 메인 문구 | 60px | 600 | 1.5 |
| Vision 설명 | 24px | 400 | 1.5 |
| 핵심 가치 제목 | 32px | 600 (후속 규칙에서 700) | 1.4 |
| 핵심 가치 본문 | 20px | 400 | 후속 규칙에서 1.7 |
| 섹션 제목(소식·SNS 등) | 42px | 700 | 1.3 |
| 섹션 더 알아보기 | 18px | 500~600 | 1 또는 1.5 |
| 공지 카드 제목 | 21px | 600 | 1.45 |
| 공지 카드 설명 | 15px | 기본값(명시된 굵기 없음) | 1.65 |
| 뉴스 날짜 | 15px | 500 | 1.4 |
| 뉴스 카드 제목 | 17px | 500 | 1.55 |
| GNB 1차 메뉴 | 16px | 500 | 별도 지정 없음 |
| GNB 하위 메뉴 | 14px | 기본값 | 1.4 |
| Footer 본문 | 15px | 400 | 1.5~1.7 |
| Footer 제목 | 16px | 700 | 1.5 |

> CSS에는 같은 요소를 대상으로 한 기본 규칙과 뒤쪽의 보정 규칙이 함께 있습니다. 핵심 가치 제목처럼 굵기가 후속 규칙에서 변경된 항목은 실제 최종 적용값을 브라우저 개발자 도구에서도 확인하세요. 위 표의 범위 표기는 코드에서 확인되는 차이를 숨기지 않기 위한 것입니다.

### 타이포그래피 적용 원칙
- 페이지의 가장 중요한 제목은 섹션 제목보다 시각적으로 우선하도록 구성합니다.
- 본문은 400을 기본으로 하고, 문장 안에서 의미를 강조할 때만 600 이상의 굵기를 사용합니다.
- 한국어 문장이 어색하게 끊기지 않도록 `word-break: keep-all`을 활용합니다.
- 자간은 제목에서 `-0.015em`부터 `-0.04em`까지 사용 사례가 확인됩니다. 모든 텍스트에 동일한 자간을 강제하지 않습니다.
- 모바일에서는 제목 크기를 줄이고 본문 줄간격을 넉넉하게 유지합니다.

## 6. Layout & Spacing — 레이아웃 및 간격

### 컨테이너와 너비
| 영역 | 코드 기준 |
|---|---|
| Header 내부 | `width: calc(100% - 8%)`, `max-width: 1600px` |
| Vision 콘텐츠 | `max-width: 1200px` |
| 주요 섹션 콘텐츠 | `max-width: 1320px` |
| GNB 메뉴 | `width: min(650px, 65%)` |
| 일반 섹션 좌우 패딩 | 주로 24px |
| 모바일 섹션 좌우 패딩 | 주로 20px |
| Header 모바일 좌우 | `width: calc(100% - 32px)` |

### 간격 변수
- `--content-gap: 20px`: 뉴스·공지·SNS 등 반복 콘텐츠 사이의 공통 간격으로 사용합니다.
- 모바일 SNS 구간의 `:root` 재정의에서 `--content-gap: 12px`로 줄어듭니다.
- 제품 캐러셀은 `--circle`, `--circle-main`, `--arrow` 변수를 사용해 화면 너비에 따라 크기를 조절합니다.

### 그리드와 Flex
- 기업 핵심 가치 영역: 이미지와 텍스트를 2열 Grid로 배치하고, 두 번째 행은 좌우 순서를 바꿉니다.
- 제품 영역: 좌우 화살표와 가운데 슬라이더를 배치하는 구조입니다.
- 우리맛 영역: 3개의 카드가 Flex 기반으로 배치되며 Hover 시 선택한 카드가 넓어지는 방식입니다.
- 공지사항: 데스크톱 4열, 1024px 이하 2열, 768px 이하 1열입니다.
- 뉴스: 데스크톱 3열, 768px 이하 1열입니다.
- SNS: 데스크톱 5열, 900px 이하 3열, 600px 이하 2열입니다.

### 섹션 여백
현재 CSS에는 섹션별로 80px, 모바일 72px 등의 상하 여백이 반복됩니다. 다만 모든 섹션이 같은 패딩을 쓰지는 않으므로 새 페이지에서는 콘텐츠 종류와 밀도에 맞춰 기존 해당 섹션 패턴을 참고합니다.

## 7. Components — 공통 UI 컴포넌트

### Header / GNB
- Header는 Hero 영상 위에 겹쳐지는 절대 위치 구조입니다.
- 데스크톱 기본 높이는 76px이며 내부 정렬 영역은 90px입니다.
- 상단 오른쪽에는 Global, 인재채용, 고객센터, 마켓 유틸리티 링크가 배치됩니다.
- GNB는 6개 1차 메뉴와 각 메뉴의 하위 링크로 구성됩니다.
- Header에 Hover하거나 내부 요소에 Focus가 들어오면 높이가 330px로 확장되고 흰색 배경 및 어두운 텍스트로 전환되며 하위 메뉴가 표시됩니다.
- 모바일(1024px 이하)에서는 유틸리티와 데스크톱 GNB를 숨기고 메뉴 토글 버튼을 표시합니다. 현재 HTML에는 토글 버튼이 있으나 메뉴를 펼치는 패널과 토글 동작 스크립트는 확인되지 않습니다. 서브페이지에서 동작을 새로 만들 경우 별도 구현·테스트가 필요합니다.

### Footer
- 전체 배경: `var(--action-primary)` (딥 레드)
- 텍스트: `var(--text-inverse)` (흰색)
- 상단 링크 영역과 하단 정보 영역을 구분선으로 나눕니다.
- 상단에는 유틸리티 링크와 SNS 아이콘을 배치합니다.
- 본문은 회사 정보와 관련 사이트·언어 드롭다운 영역으로 나뉩니다.
- 드롭다운은 버튼으로 열고 닫으며, 다른 드롭다운을 열면 기존 메뉴를 닫습니다. 바깥 영역 클릭과 Escape 키로도 닫힙니다.
- 현재 드롭다운 선택은 표시 문구를 변경하는 UI이며, 실제 외부 페이지 이동이나 언어 전환 기능은 연결되어 있지 않습니다.

### 버튼 및 링크
- 섹션의 “더 알아보기”는 둥근 Pill 형태이며 `border-radius: 999px`, 최소 높이 46px, 좌우 패딩 28px입니다.
- 모바일에서는 최소 높이 38px, 좌우 패딩 18px, 글자 크기 14px로 축소됩니다.
- 버튼 Hover 시 글자는 흰색, 배경은 `--action-primary-hover`로 바뀝니다.
- 버튼 오른쪽에 화살표가 표시되고 Hover 시 오른쪽으로 4px 이동합니다.
- GNB 링크는 Hover/Focus 시 밑줄이 중앙에서 너비 28px로 나타납니다.

### 카드
- **공지 카드:** 4열 Grid, 최소 높이 370px, 내부 패딩 45px, 회색 배경, 둥근 모서리. Hover 시 위로 5px 이동하고 배경색이 바뀝니다. 모바일에서는 최소 높이 220px, 패딩 24px입니다.
- **뉴스 카드:** 이미지, 날짜, 제목 순서. 이미지 Hover 시 1.04배 확대됩니다.
- **SNS 카드:** 이미지 중심 카드이며 Hover 시 이미지가 1.04배 확대됩니다.
- **우리맛 카드:** 배경 이미지와 텍스트를 겹쳐 배치하고, Hover/Focus 시 이미지가 1.07배 확대됩니다. 카드 확장 효과는 메인 CSS의 Flex 규칙을 따릅니다.
- **제품 카드:** Swiper 구조를 사용하며 카테고리 탭과 이전/다음 버튼으로 제품을 탐색하도록 구성되어 있습니다. 슬라이드 크기·간격은 기존 제품 영역 CSS와 Swiper 설정을 함께 확인해야 합니다.

### 이미지
- 뉴스·SNS·우리맛·기업 가치 이미지 등 콘텐츠 이미지는 컨테이너를 채우고 `object-fit: cover`를 사용해 표시합니다.
- 이미지가 잘리는 경우 콘텐츠의 핵심 피사체가 보이도록 `object-position`을 조정합니다.
- 장식 이미지가 아닌 콘텐츠 이미지에는 의미에 맞는 `alt`를 작성합니다.
- 메인 페이지에서 이미지 모서리 20px을 공통 적용하는 선택자가 존재합니다. 모든 이미지가 아니라 지정된 이미지 컨테이너에 적용된 규칙이므로 로고·영상·제품 원형 이미지까지 무조건 둥글게 만들지 않습니다.

## 8. Interaction — 인터랙션

### Hover / Focus
- GNB 1차 메뉴: Hover 및 Focus-within에서 하위 메뉴 표시, 밑줄 강조.
- GNB 하위 링크: Hover/Focus 시 브랜드 레드로 변경.
- 카드: 공지 카드는 위로 5px 이동, 뉴스·SNS 이미지는 1.04배 확대, 우리맛 이미지는 1.07배 확대.
- 더 알아보기 버튼: 배경과 글자색 변경, 화살표가 오른쪽으로 4px 이동.
- Footer 드롭다운 옵션: Hover/Focus 시 텍스트와 배경 강조.

### Active / 선택 상태
- 제품 카테고리 탭은 `.is-active` 클래스와 `aria-selected` 속성으로 현재 선택 상태를 표현합니다.
- 제품 이전/다음 버튼은 슬라이더 탐색을 위한 컨트롤입니다.
- 드롭다운은 `.is-open` 클래스와 `aria-expanded` 속성으로 열린 상태를 표현합니다.

### Transition / Scroll
- Header: 높이·배경색·글자색 전환 0.25초.
- 카드 이미지: transform 전환 0.3초(우리맛 이미지는 0.65초).
- 버튼: 색상 전환 0.2초.
- Vision 문구: `.fade-in`의 opacity 전환 1초.
- 기업 가치 이미지와 텍스트: `.fade-up`의 opacity 및 translateY 전환 0.9초. IntersectionObserver로 화면에 들어오면 `.is-visible`을 추가합니다.
- `prefers-reduced-motion: reduce` 환경에서는 스크롤 애니메이션을 줄이거나 제거하도록 처리합니다.

### 접근성
- 공통 초기화 CSS는 `:focus-visible`에 2px outline과 2px offset을 적용합니다.
- 키보드 사용자가 Hover와 유사한 메뉴 접근을 할 수 있도록 `:focus-within`을 함께 사용합니다.
- 메뉴 버튼에는 `aria-label`, 탭에는 `role="tab"` 및 `aria-selected`, 드롭다운에는 `aria-expanded`와 `aria-controls`를 사용합니다.
- 새 컴포넌트에도 키보드 Focus 상태와 적절한 ARIA 상태를 유지합니다.

## 9. Responsive Rules — 반응형 기준

현재 코드에서 확인되는 주요 분기점은 1400px, 1024px, 900px, 768px, 600px입니다. 모든 컴포넌트가 모든 분기점을 사용하는 것은 아닙니다.

| 화면 기준 | 적용 규칙 |
|---|---|
| 1400px 이하 | 기업 가치 이미지가 고정 670px에서 유동 비율로 전환. SNS 5열 카드 폭을 유동적으로 조정 |
| 1024px 이하 | Header 모바일 구조로 전환. 공지사항은 2열. Footer는 세로 방향 배치 |
| 900px 이하 | SNS 그리드를 3열로 변경 |
| 768px 이하 | 주요 섹션 패딩 축소. 기업 가치·뉴스·공지사항은 1열. 모바일용 제목·본문 크기 적용 |
| 600px 이하 | SNS 그리드를 2열로 변경하고 공통 콘텐츠 간격을 12px로 축소 |

### 반응형 제작 원칙
- 컨테이너는 `width: 100%`와 `max-width`를 조합해 화면 너비 안에서 유동적으로 사용합니다.
- 카드 그리드는 화면이 좁아질수록 열 수를 줄입니다.
- 이미지와 텍스트가 2열인 콘텐츠는 모바일에서 1열로 쌓습니다.
- 모바일에서 제목은 축소하되 본문 가독성과 터치 영역을 유지합니다.
- 제품 원형 이미지와 화살표는 CSS의 `clamp()` 변수를 사용해 화면 크기에 맞춰 조절합니다.
- 실제 모바일 메뉴 토글은 현재 구현 여부를 별도로 확인해야 합니다.

## 10. Do & Don't — 반드시 지킬 규칙과 금기사항

### Do
- 기존 CSS 변수(`--red-deep`, `--text-primary`, `--surface-default` 등)를 우선 사용합니다.
- 새 서브페이지도 Pretendard Variable을 사용합니다.
- 페이지 제목, 본문, 보조 정보의 위계를 분명히 합니다.
- 주요 콘텐츠의 최대 너비와 좌우 정렬 기준을 기존 섹션과 맞춥니다.
- 카드·버튼·링크의 Hover와 Focus 상태를 함께 설계합니다.
- 모바일에서 그리드 열 수와 여백을 줄이고 콘텐츠 순서를 자연스럽게 조정합니다.
- 이미지에 적절한 대체 텍스트를 작성하고, 장식 이미지는 의미에 맞게 처리합니다.
- 실제 링크 목적지가 정해지지 않았다면 임의의 기존 브랜드 사이트 주소를 연결하지 않습니다. 페이지 내부 임시 링크는 실제 이동 기능이 있는 것처럼 표시하지 않습니다.

### Don't
- Figma/CSS에 없는 새 브랜드 컬러나 수치를 근거 없이 만들지 않습니다.
- 동일한 역할의 요소에 서로 다른 빨간색·회색을 임의로 추가하지 않습니다.
- 모든 이미지와 요소에 무조건 20px 모서리 반경을 적용하지 않습니다.
- 서브페이지마다 Header, GNB, Footer를 별도 디자인해 서로 다르게 만들지 않습니다.
- Hover만 제공하고 키보드 Focus 상태를 누락하지 않습니다.
- 모바일에서 데스크톱 고정 너비와 다단 그리드를 그대로 유지하지 않습니다.
- 확인되지 않은 외부 URL이나 기존 브랜드 사이트 주소를 링크로 임의 연결하지 않습니다.
- 메인 페이지의 기존 HTML/CSS/JS를 이 문서를 작성하는 과정에서 변경하지 않습니다.

## 확인 메모 및 구현상 주의사항

1. `sempio/css/main.css`의 `body`에는 현재 `background-color: yellow;`가 남아 있습니다. 일반적인 브랜드 배경 토큰과 다른 디버그용 설정처럼 보이지만, 문서 작성 과정에서는 메인 페이지를 변경하지 않기 위해 수정하지 않았습니다. 서브페이지에 그대로 복사하지 말고 실제 의도된 배경을 확인하세요.
2. 제품 영역 HTML에는 Swiper 클래스가 있고 외부 스크립트 경로 `../npm/swiper/swiper-bundle.min.js`가 선언되어 있습니다. 배포·실행 환경에서 해당 파일 경로가 유효한지 확인해야 합니다.
3. CSS에는 기본 규칙 뒤에 보정 규칙이 추가된 부분이 있습니다. 같은 선택자에 속성이 중복되면 CSS에서 나중에 선언된 규칙이 우선할 수 있으므로, 새 페이지에서 값을 복사하기 전에 최종 계산 스타일을 확인하세요.
4. 현재 메인 페이지 링크 중 다수는 `href="#"`로 되어 있습니다. 실제 페이지 경로가 정해지기 전까지 외부 브랜드 사이트 주소를 임의로 넣지 않습니다.
5. 이 문서는 코드에 존재하는 스타일 규칙을 바탕으로 작성했습니다. 화면 캡처나 Figma 원본과 대조하지 않은 값은 추측해 추가하지 않았습니다.
